wikiの内容をもとに質問に回答します。

## 使い方
- `/query <質問>` — 質問を指定して回答
- `/query` — 引数なしの場合は何を知りたいかを聞く

## 実行フロー

### Step 1: 関連ページの特定
`wiki/index.md` を読んで質問に関連するページを特定する。

### Step 2: ページ読み込みと回答
関連する概念ページ・エンティティページ・ソースサマリーを読み込み、日本語で回答を合成する。
- ソースページへの引用 `[[sources/xxx]]` を含める
- wikiに情報がない場合は「wikiには記録がない」と明示し、必要なら新規ingestを提案

### Step 3: 回答のwiki保存（オプション）
回答が有益な分析・比較・考察を含む場合、wikiページとして保存するか確認する。
保存する場合は `wiki/concepts/` や `wiki/` 直下に適切なページを作成し、index.mdとlog.mdを更新する。
