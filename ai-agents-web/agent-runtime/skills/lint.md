wikiのヘルスチェックを行い、品質を維持します。

## 使い方
`/lint` のみ（引数なし）

## 実行フロー

### Step 1: 全ページスキャン
`wiki/index.md` を起点に全ページを読み込んでチェックリストを作成する。

### Step 2: 問題の検出

以下の問題を探す:

**矛盾・陳腐化**
- 複数ページで相互に矛盾する記述
- 新しいソースの情報で更新すべき古い記述

**リンク問題**
- 被リンクが1件もない孤立ページ
- リンク先が存在しない壊れたリンク
- index.mdに載っていないページ

**カバレッジ不足**
- 複数のページで言及されているが専用ページがない重要概念
- ソースページに関連エンティティへのリンクが欠けている箇所

**構造的な問題**
- CLAUDE.mdのフォーマットから大きく外れているページ
- 内容が薄すぎてほぼ情報のないページ（スタブ）

### Step 3: 結果報告と修正提案
問題をカテゴリ別にリストアップし、ユーザーに報告する。修正方針を確認してから実施する。

### Step 4: 修正実施とログ記録
承認された修正を実施し、`wiki/log.md` に記録する:
```
## [YYYY-MM-DD] lint | 定期ヘルスチェック
- 修正: （修正した問題の一覧）
- 提案: （次に調査すべきトピックや補強すべき分野）
```
