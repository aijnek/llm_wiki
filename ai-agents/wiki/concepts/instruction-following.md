# 指示追従能力（Instruction Following）

## 定義

LLMが与えられた指示の内容・制約・終了条件を正確に解釈し、複数ターンにわたって追従し続ける能力。特に「ルールに従って状態を持ちながら判断を続ける系のタスク」における追従性を指すことが多い。

## 背景

LLMの能力評価はベンチマーク（HumanEval等）が中心だったが、実際のエージェントシステムでは「複雑なルールを長時間守り続けられるか」という次元が重要になる。ハーネスエンジニアリングの観点から「モデルによって必要なハーネスが変わる」という命題を検証するために、この次元の評価が行われるようになった。

## 詳細

### モデルと難易度の境界

個人実験（2026年5月）で7段階のタスク難易度と6モデルを組み合わせた観察が行われた。結果:

| モデル | 到達タスク | 主な失敗パターン |
|---|---|---|
| Qwen3.5 4B | Task 1 | — |
| Qwen3.5 9B | Task 1 | Task 2: 終了条件の誤解釈 |
| Qwen3.5 27B | Task 2 | Task 3: 単調増加判定の無視 |
| Haiku 4.5 | Task 2 | Task 3: 単調増加判定の無視 |
| Sonnet 4.6 | Task 6 | Task 7: 複数終了条件の扱いを誤る |
| Opus 4.7 | Task 7（全完遂） | — |

### 状態遷移系タスクとの親和性

「ルールに従って状態を持ちながら判断を続ける系のタスク」は、過去の出力にすべての必要情報が残るため、自己回帰的に出力を生成するLLMと本質的に親和性が高い。問題は「長距離依存を捉えるキャパシティ」にある。

詳細は [[state-machine-tasks]] を参照。

### 状態出力ハーネスによる補完

各ステップで現在の状態を明示的に出力させる指示があると、小さなモデルでも複雑なタスクへの追従精度が向上する。Sonnet 4.6はTask 6（状態出力指示なし）で自発的に状態出力を行ってカバーした事例がある。これはハーネスがモデルの能力を補完できることを示す。
